1. From code to published site

All content is resolved at build time. The only network read during compilation is the public GitHub API. Live data is requested later, from the browser.

4. Laboratories: component → endpoint

There are six laboratories (labDisplayOrder in PortfolioPage.astro): home-status, container-metrics, meshtastic, meshtastic-status, printer and signal-relay. meshtastic-status is not its own card: PortfolioPage passes it to MeshtasticLab, which embeds MeshtasticStatusLab.

Each card is an Astro component with a browser <script>. All of them read from https://lab.destaben.dev in production or http://127.0.0.1:8787 locally (data-production-url / data-local-url attributes) and fall back to an “unavailable” state if the response fails.

5. Signal Relay (services/signal-relay/)

Standalone FastAPI service, not part of Pages. A single bridge that speaks web (HTTP/WSS) and Reticulum; no secret lives in the repository.

app.py 362 lines

Defines the public routes, the CORS middleware and the WebSocket. Laboratory routes use include_in_schema=False. The printer routes return 404 until SIGNAL_RELAY_PRINTER_ENABLED is true.

config.py 373 lines

Reads the environment into Settings and, at startup, rejects malformed entity IDs, non-public TCP node aliases or URLs and invalid channel filters, never echoing the value in the error.

bridge.py 458 lines

Persistent LXMF identity and destination, bounded inbox, rate limiting, educational sessions (LabSession), Prometheus metrics and Telegram notices after the message is stored.

home_assistant.py 624 lines

Three clients on a common base: no redirects, responses ≤ 1 MiB, a 5 s budget, a 15 min minimum cache and failures remembered for 30 s. Builds the public projections and fires the fixed broadcast event.

printer.py 724 lines

Single-flight Moonraker client, metadata/thumbnail cache, HMAC-based modelId and a background worker that downloads and parses the G-code.

gcode_model.py 398 lines

Streaming parser: layers from ;LAYER_CHANGE, outer wall only, 0.1 mm quantization and Douglas-Peucker simplification with size caps.

metrics.py, telegram.py, lab_sender.py

Fixed cAdvisor queries to Prometheus, the Telegram notifier and an isolated process that sends once with a temporary identity.

scripts/ and container

preflight.sh, deploy.sh, verify.sh and rollback.sh run the deployment; Dockerfile + compose.yaml define the image and the network.

6. Tests and CI/CD

Node tests/*.test.mjs

site-output inspects the generated HTML, printer-lab, signal-relay-lab and relay-view test the pure rules, relay-deployment checks the Compose manifest. They run with npm test after the build.

Python services/signal-relay/tests

pytest for the app, Home Assistant/Meshtastic, printer, G-code parser and Telegram.

npm run verify

astro check + build + Node tests. This is the command CI and deployment use.
