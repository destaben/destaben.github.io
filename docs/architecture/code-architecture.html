1. Del código al sitio publicado

Todo el contenido se resuelve en tiempo de build. Las únicas lecturas de red durante la compilación son la API pública de GitHub. Los datos en vivo se piden después, desde el navegador.

5. Signal Relay (services/signal-relay/)

Servicio FastAPI independiente, no incluido en Pages. Un único puente que habla web (HTTP/WSS) y Reticulum; ningún secreto vive en el repositorio.

app.py 362 líneas

Define las rutas públicas, el middleware CORS y el WebSocket. Las rutas de laboratorio aparecen con include_in_schema=False. Las del taller de impresión devuelven 404 mientras SIGNAL_RELAY_PRINTER_ENABLED no sea true.

config.py 373 líneas

Lee el entorno en Settings y rechaza al arrancar IDs de entidad mal formados, alias o URLs de nodos TCP no públicos y filtros de canal inválidos, sin repetir el valor en el error.

bridge.py 458 líneas

Identidad y destino LXMF persistentes, bandeja acotada, limitación de tasa, sesiones educativas (LabSession), métricas Prometheus y avisos a Telegram tras guardar el mensaje.

home_assistant.py 624 líneas

Tres clientes sobre una base común: sin redirecciones, respuestas ≤ 1 MiB, presupuesto de 5 s, caché mínima de 15 min y fallo recordado 30 s. Genera las proyecciones públicas y publica el evento fijo de difusión.

printer.py 724 líneas

Cliente Moonraker de un solo vuelo, caché de metadatos/miniaturas, modelId con HMAC y worker de fondo que descarga y analiza el G-code.

gcode_model.py 398 líneas

Parser en streaming: capas por ;LAYER_CHANGE, solo pared exterior, cuantización a 0,1 mm y simplificación Douglas-Peucker con límites de tamaño.

metrics.py, telegram.py, lab_sender.py

Consultas fijas de cAdvisor a Prometheus, notificador de Telegram y proceso aislado que envía una vez con identidad temporal.

scripts/ y contenedor

preflight.sh, deploy.sh, verify.sh y rollback.sh operan el despliegue; Dockerfile + compose.yaml definen la imagen y la red.

6. Tests y CI/CD

Node tests/*.test.mjs

site-output inspecciona el HTML generado, printer-lab prueba las reglas puras, relay-deployment comprueba el manifiesto Compose. Se ejecutan con npm test tras el build.

Python services/signal-relay/tests

pytest para app, Home Assistant/Meshtastic, impresora, parser G-code y Telegram.

npm run verify

astro check + build + tests de Node. Es el comando que usan CI y despliegue.

WorkflowDisparadorQué hace
ci.ymlPR a main, manualSolo lectura: pytest del relay, docker compose config, npm run verify. No despliega. Jobs «Signal Relay tests» y «Site check, tests and build».
